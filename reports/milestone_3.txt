2. PLAIN-ENGLISH GUIDE TO OUR METRICS
-------------------------------------
Because NBA home teams win ~58-60% of games, accuracy alone does not
tell the whole story. We implemented 7 metrics from scratch in
metrics.py:

  - Confusion Matrix (TN, FP, FN, TP):
      Splits every test prediction into four buckets:
        * TP (True Positive)  : Predicted Home Win, Home actually won.
        * TN (True Negative)  : Predicted Away Win, Away actually won.
        * FP (False Positive) : Predicted Home Win, Away actually won.
        * FN (False Negative) : Predicted Away Win, Home actually won.
  - Accuracy  : Overall % of games predicted correctly.
  - Precision : When our model picks the home team, how often is it
                right? = TP / (TP + FP).
  - Recall    : Out of all actual home wins, how many did our model
                catch? = TP / (TP + FN).
  - F1-Score  : Single number balancing Precision and Recall.
  - ROC-AUC   : Measures how well the model ranks true home wins ahead
                of away wins across every probability cutoff (0.50 =
                random guessing, 1.00 = perfect ranking).
  - Log-Loss  : Checks how trustworthy the win probabilities are (lower
                is better). Being 95% confident on a wrong pick gets a
                much heavier penalty than being 55% confident.

5-Fold Expanding-Window Time-Series CV:
Instead of testing on only one 80/20 split, we divide the 931 games
(in date order) into 6 chronological blocks (~155 games each). In each
fold, we train on all earlier blocks and test on the next unseen block
(scaling features strictly inside each training fold). This tests how
consistently each model performs across the entire NBA season without
ever peeking into the future.

4. KEY FINDINGS & WHAT THE CHARTS SHOW
--------------------------------------
  1) Why Accuracy & F1 Alone Are Not Enough:
     The "Always Pick Home" baseline gets a 73.65% F1-score simply
     because it catches 100% of home wins while missing every single
     away win (TN = 0). Looking at ROC-AUC (0.500 = coin flip) and the
     confusion matrices makes it immediately obvious that all three
     learned models provide real predictive value (AUC 0.655 to 0.678).

  2) Logistic Regression Is Most Consistent Across the Full Season:
     Logistic Regression tied for the highest test accuracy (63.10%),
     achieved the highest F1-score (74.16%), and led 5-fold time-series
     CV at 61.98% (+/- 2.28% across folds) vs. 59.54% baseline. Its
     confusion matrix shows it leans heavily toward home picks (99/109
     home wins caught, but only 19/78 away wins caught), which suggests
     tuning regularization or its decision threshold could help.

  3) KNN (k=15) Has the Best Probability Calibration (Lowest Log-Loss):
     KNN tied for the best test accuracy (63.10%) and achieved the best
     Log-Loss (0.6370), because averaging 15 neighbors naturally keeps
     predicted probabilities reasonable instead of extreme. It is also
     more balanced than Logistic Regression at spotting road wins
     (TN = 32 vs. 19), though prediction is slower (8.3 ms) because it
     compares against all 744 training games.

  4) Gaussian Naive Bayes Ranks Well (Best AUC) but Is Overconfident:
     Gaussian NB posted the top ROC-AUC (0.678) and ran in under 0.3 ms
     total, yet had the highest Log-Loss (0.7049--worse than the
     baseline!). Why? Naive Bayes assumes all 23 stats are completely
     independent. Because stats like home_win_pct, diff_win_pct, and
     home_avg_point_diff are correlated, it effectively "double-counts"
     the same signal and produces overly extreme probabilities near 0%
     or 100%.


5. NEXT STEPS FOR MILESTONE 4
-----------------------------
Using 5-fold expanding-window CV on the training data (without peeking
at the held-out test set), we can tune simple settings for each model:
  - KNN                 : Test different neighborhood sizes k (e.g. 5 to 45).
  - Gaussian NB         : Test variance smoothing / smaller uncorrelated
                          feature subsets to reduce overconfidence.
  - Logistic Regression : Test learning rates, training epochs, and
                          light L2 regularization to stabilize weights.
